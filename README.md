# אפולו 9662 – פרוטוטייפ ירי גלגל מעל גלגל

מאגר הקוד של פרויקט "02 פרוטוטייפ ירי", עונת ביובאז.

## מה יש כאן

- `generator/` – המחולל שבונה את המודל באינוונטור (פייתון שמייצר כללי iLogic). גרסה פעילה: 4b.
- `simulator/` – סימולטור הירי התלת־ממדי, קובץ HTML אחד.

## מה אין כאן

- קובצי שרטוט ומודל (ipt, iam, STEP, STL, PDF) – בדרייב, בתיקייה "02 פרוטוטייפ ירי / מודל".
- נתוני ניסויים ומדידות – בדרייב, בתיקייה "מדידות ובדיקות".
- סודות, מפתחות וכתובות שרת – בקובץ הגדרות מקומי שמוחרג מהמאגר.

## כללי בטיחות (החלטה 02)

1. אין סודות בקוד.
2. אין נתונים במאגר, רק קוד.
3. לפני כל דחיפה עוברים על מה שנדחף.
